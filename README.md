# 🚗 ParkNexa — Smart Parking Management System

> A modern full-stack web application for managing parking locations,
> parking slots, availability and parking operations through a centralized dashboard.

---

## 📌 Overview

**ParkNexa** is a Smart Parking Management System developed using
**Java Spring Boot, React.js and MySQL**.

The application provides a centralized platform to manage multiple parking
locations and their individual parking slots. Administrators can create,
update, view and delete parking locations and slots, monitor parking
availability, and filter slots based on their current status or location.

The main goal of ParkNexa is to replace manual parking management with a
simple, structured and scalable digital solution.

---

## 🎯 Project Objective

The objective of ParkNexa is to digitally manage parking infrastructure
from a single platform.

The system focuses on:

- Managing multiple parking locations
- Managing parking capacity
- Creating and managing individual parking slots
- Tracking slot availability
- Tracking occupied slots
- Filtering slots by status
- Filtering slots by parking location
- Providing a centralized parking dashboard
- Reducing manual parking management
- Creating a foundation for future smart parking features

---

## 💡 Problem Statement

Traditional parking facilities may rely on manual monitoring and
disconnected records to understand parking availability.

This can make it difficult to:

- Know the current parking capacity
- Track individual parking slots
- Identify available slots quickly
- Monitor occupied slots
- Manage multiple parking locations
- Maintain parking information efficiently
